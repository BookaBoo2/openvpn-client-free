# Политика конфиденциальности — OpenVPN Client Free

**Дата:** 2026-08-14  
**Приложение:** OpenVPN Client Free (Android)

## Кратко

Приложение **не отправляет** ваши VPN-профили, пароли и трафик на серверы разработчика. Все данные хранятся **локально на устройстве**.

## Какие данные обрабатываются

| Данные | Где хранится | Передаётся разработчику |
|--------|--------------|-------------------------|
| Файлы `.ovpn` / конфигурация | Память приложения на устройстве | Нет |
| Логин и пароль VPN (если указаны) | Зашифрованное хранилище Android | Нет |
| Список выбранных приложений (whitelist/blacklist) | Память приложения | Нет |
| Логи подключения | Файл в каталоге приложения | Нет |
| Список установленных приложений | Только для выбора в UI, не сохраняется отдельно | Нет |

## VPN-трафик

VPN-туннель устанавливается **напрямую** между вашим устройством и VPN-сервером, указанным в профиле `.ovpn`. Разработчик приложения **не является** посредником и **не имеет доступа** к вашему трафику.

## Разрешения Android

- **INTERNET, ACCESS_NETWORK_STATE** — для VPN-подключения
- **BIND_VPN_SERVICE / VpnService** — создание VPN-туннеля
- **QUERY_ALL_PACKAGES** — отображение списка приложений для whitelist/blacklist
- **POST_NOTIFICATIONS** — уведомление о статусе VPN (foreground service)
- **FOREGROUND_SERVICE** — работа VPN в фоне

## Сторонние сервисы

При **сборке** приложения Gradle может загружать зависимости с Maven/JitPack. Это не относится к работе установленного приложения у конечного пользователя.
