# OpenVPN Client Free

**Свободный клиент OpenVPN для Android** с поддержкой нескольких профилей `.ovpn` и маршрутизацией по приложениям (белый / чёрный список).

> **OpenVPN®** — зарегистрированный товарный знак [OpenVPN Inc.](https://openvpn.net/)  
> Это приложение **не является** официальным продуктом OpenVPN Inc. и **не аффилировано** с ним. Поддерживается протокол OpenVPN через файлы конфигурации `.ovpn`.

---

## Возможности

- Импорт профилей: **из файла** или **вручную** (вставка текста)
- Несколько профилей, выбор активного, профиль по умолчанию
- Подключение / отключение OpenVPN
- Фильтр приложений на профиль:
  - **Все** — весь трафик через VPN
  - **Белый список** — только выбранные приложения через VPN
  - **Чёрный список** — выбранные приложения обходят VPN
- Логин и пароль (локально, зашифрованное хранилище)
- Логи подключения
- Экран **«О программе»** со ссылкой на исходный код (GPL)

## Сборка

### Требования

- Flutter 3.22+ (SDK Dart 3.12+)
- Android SDK, **minSdk 24**, compileSdk 36
- JDK 17
- Доступ к [JitPack](https://jitpack.io) (зависность `openvpn_library`)

### Команды

```bash
git clone https://github.com/BookaBoo2/openvpn-client-free.git
cd openvpn-client-free
flutter pub get
flutter run
# release APK:
flutter build apk --release
```

APK: `build/app/outputs/flutter-apk/app-release.apk`

### Структура проекта

```
lib/                    # Flutter UI
packages/vpn_android/   # Android-плагин (VpnService, профили, OpenVPN)
android/                # Host-приложение
docs/                   # Лицензии и уведомления
```

## Использование

1. Импортируйте `.ovpn` (вкладка **По файлу** или **Вручную**)
2. При необходимости настройте фильтр приложений в профиле
3. На главном экране выберите профиль и нажмите **Подключить**
4. Подтвердите разрешение VPN в системе Android

Смена белого/чёрного списка на активном соединении требует **переподключения**.

## Конфиденциальность

Профили, пароли и логи **не отправляются** разработчику. VPN-туннель идёт напрямую на **ваш** сервер из `.ovpn`.  
Подробности: [PRIVACY.md](PRIVACY.md)
